# Realization of a Modern Data Center Network Architecture
We designed and simulated a modern data center using a Spine-Leaf topology across four cabinets, eight ToR leaf switches, and two EoR spine switches, with redundant firewalls enforcing zone-based security between a Trust zone (Cabinets A, B, C - database and application servers) and a DMZ (Cabinet D - web servers). The full environment was simulated in PNETLab with Arista vEOS switches, pfSense firewalls, and Debian Linux servers, and validated through connectivity and failover testing.
